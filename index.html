how orbz stays safe

user message→Claude→tool call→approval gate→execute→run log

Read-only tools run straight away. Everything that reaches outside the app stops and asks. Full diagram and code →

Approval gate

Side-effecting tools wait for an explicit approve or deny. The decision is logged once and can't be replayed.

SSRF-safe fetch

Public hosts only. Every resolved IP is checked, redirects are re-validated per hop, body capped, 8s timeout.

Untrusted tool output

The model is told that MCP output is data, never instructions. A dead server is skipped, never fatal.

Fails closed

No password configured means nobody gets in. HMAC sessions, constant-time compare, auth re-checked in every server action.
